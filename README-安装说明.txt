当前可体验
- 查找附近充电站、查看枪状态和示例价格
- 选择充电限额并浏览模拟充电流程

- 查看含 VAT 拆分的示例收据

安装到 iPhone
1. 需要先把本文件夹部署到 HTTPS 网站。
2. 在 iPhone 的 Safari 打开部署网址。
3. 点“分享”→“添加到主屏幕”，再从主屏幕打开 AFE Charge。

测试提醒
这是交互原型，不连接真实账户、充电桩、OCPP、银行卡或支付服务。卡号末四位、余额、车辆和充电记录均为示例；请勿输入真实个人或支付资料。公开测试站点需要将本包发布后才会更新。
